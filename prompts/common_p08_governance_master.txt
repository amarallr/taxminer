# 2. CONTEXT — CONTEXTO

O TaxMiner é uma plataforma de coleta, consolidação, estruturação e análise inteligente de documentos e dados públicos tributários, contábeis e financeiros.

Possui três módulos funcionais principais:

1. TaxMiner Collect.
2. TaxMiner Data.
3. TaxMiner Intelligence.

Implementar um quarto componente transversal:

**TaxMiner Governance — AI Requirements & Execution Management.**

Esse componente será responsável por governar as solicitações, requisitos, tarefas, agentes, execuções, testes, evidências, decisões e entregas de todos os módulos.

Integrar-se ao processo de gerenciamento existente, especialmente ao Common P01.

Não substituir controles existentes sem análise de compatibilidade e autorização.

# 3. MISSION — MISSÃO

Criar um sistema capaz de transformar solicitações informais submetidas a Claude Code, Codex, Copilot e, futuramente, Gemini CLI em um processo estruturado, rastreável, otimizado e auditável de engenharia de software.

Toda solicitação capturada deverá passar pelo seguinte fluxo:

**INPUT → CLASSIFICATION → CONTEXT ANALYSIS → REQUIREMENTS ENGINEERING → TOKEN OPTIMIZATION → PLANNING → AUTHORIZATION → EXECUTION → TESTING → EVIDENCE → ACCEPTANCE → DELIVERY → MONITORING**

A captura automática depende das capacidades reais de integração de cada agente.

Quando não houver interceptação automática, disponibilizar um ponto central de entrada e mecanismos de registro manual.

Não declarar cobertura universal sem comprovação.

# 4. FUNDAMENTAL PRINCIPLE — GOVERNANÇA EVOLUTIVA

Este prompt não deverá funcionar apenas como uma instrução estática.

Ele deverá estabelecer um mecanismo de **Continuous Prompt Improvement**, no qual o planejamento e as instruções operacionais sejam revisados durante todo o ciclo de desenvolvimento.

A cada etapa:

1. Recuperar o estado persistido do projeto.
2. Identificar o objetivo autorizado.

4. Identificar mudanças de contexto.
5. Revisar o planejamento.

10. Validar resultados.
11. Registrar evidências.
12. Atualizar o dashboard.
13. Preparar a etapa seguinte.

**Regra essencial:** a revisão do prompt não poderá eliminar, enfraquecer ou reinterpretar silenciosamente requisitos, controles de segurança ou decisões aprovadas.

- Under Analysis.
- Planned.
- Awaiting Approval.
- Approved.
- In Progress.
- Blocked.
- Implemented.
- Under Testing.
- Tested.
